⚙️ Управление сайтом

Загрузка настроек…

Если сайт выключен, игроки не смогут открывать кейсы, играть в режимы или использовать функции сайта. Администратор сможет включить его обратно. Настройки синхронизируются через Firebase.

☁️ Cloud setup (нужно для друзей)

1) Зайди на console.firebase.google.com → Create project (бесплатно)
2) Build → Realtime Database → Create → Start in test mode
3) Скопируй URL вида https://xxx-default-rtdb.firebaseio.com
4) URL уже зашит в этот файл. Другу просто отправь этот HTML — Cloud включится сам. Менять URL нужно только если создашь новую базу.
